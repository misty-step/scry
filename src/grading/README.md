# exact-v2 consumer reference

[SPEC US-017](../../SPEC.md#us-017-get-an-exact-verdict-and-a-word-by-word-diff)
owns grading behavior. `grading::grade` is the pure seam for #315. Attempt
recording, HTTP, CLI, scheduling, corrections, and held feedback belong to #317.

```rust
grade(
	version: Version<'_>,       // all Units and the Spelling-strict flag
	units: Range<usize>,        // one Unit or a contiguous Recitation
	answer: &str,
	siblings: &[SiblingVersion<'_>],
) -> Result<Grade, GradeError>
```

`Version.units` contains the entire Version so the Slip check sees words in
unrecited Units. An empty or out-of-bounds selection returns `InvalidUnitRange`.
Unit indices in the result refer to that full Version, not the selected slice.

`Grade` contains the overall Verdict, each selected Unit's Verdict, the Diff,
an optional sibling hint, and Authority `exact-v2` with `GRADER_VERSION`.
Spelling-strict changes a Slip's Verdict while preserving the visible Slip.
Each Diff entry contains an expected word, a typed word, or both. Original
text and UTF-8 byte spans survive normalization. Expected spans are relative
to their Unit; typed spans are relative to the complete answer.

## Alignment conventions

Normalization uses pinned Unicode 17 NFKC followed by default full case folding
(CaseFolding statuses C and F, not locale-specific T). Dashes separate words.
Other punctuation is stripped, except apostrophes inside words. Ampersands
become `and`. Digits, symbols, and diacritics remain significant.

The word edit distance charges one for substitution, insertion, deletion, or
an adjacent transposition. Equal-cost paths prefer a diagonal, then a
transposition, then a missing word, then an extra word. Transpositions mark
both affected words `wrong` with `out_of_order: true`, including across Units.
The Diff follows expected reading order. Each extra word belongs to the
preceding expected word's Unit; leading extras belong to the first selected Unit.

Slip detection counts Unicode letters in the normalized expected word.
The single edit must insert, delete, substitute, or transpose letters.
Editing an apostrophe, digit, symbol, or combining mark is not a Slip.

The caller supplies siblings of the same Work and the text corresponding to
the selected Prompt. Siblings may have different Unit boundaries. Only an
Again result can have a hint. The closest sibling must have strictly smaller
normalized word edit distance than the studied text. Ties use sibling ID,
then name. A hint never changes the Verdict.

## Unicode tables and verification

`unicode_tables.rs` contains generated data, not a runtime dependency. Source
hashes are pinned in `scripts/generate-exact-unicode.py`; the data license is
in `UNICODE-LICENSE.txt`. A grader behavior or Unicode data change requires a
new `GRADER_VERSION` so a recorded result identifies its rules.

The input files are `UnicodeData.txt`, `CaseFolding.txt`,
`DerivedNormalizationProps.txt`, and `NormalizationTest.txt` from
<https://www.unicode.org/Public/17.0.0/ucd/>. Given their directory, these
commands check the generated bytes and the official normalization vectors:

```sh
python3 scripts/generate-exact-unicode.py /path/to/ucd --check
SCRY_UNICODE_DATA=/path/to/ucd cargo test --locked --lib unicode_17_conformance -- --ignored --nocapture
cargo test --locked --test exact_v2 -- --nocapture
```

`unicode_17_conformance` is ignored in ordinary runs because it requires the
external data files. It verifies their hashes before checking all five
columns of every normalization row and every default full case-fold mapping.
The ordinary suite includes multilingual examples through the public seam.

The clause-four Recitation fixture is authored synthetic text. The sibling
fixture uses the short Spirit/Ghost contrast. These fixtures prove module
behavior, not a supplied Roman Missal Version, the HTTP/CLI practice journey,
phone acceptance, or a deployed service. US-017's evidence remains pending.

## Supplied keyed-mapping profile

`grade_mapping` reuses the deterministic aligner, strict Slip policy and full
Unicode17 tables. Its Authority remains `exact-v2`, but its pinned grader version
is `1;unicode=17.0.0;mapping=1`. Punctuation creates word boundaries instead of
silently joining letters; ampersands are not expanded to "and". Dashes separate
words, interior apostrophes remain significant, and NFKC/case-folding and
whitespace rules are shared. Thus `x ray` matches `X-ray`, while `Xray` and
`a.l.f.a` do not match `X-ray` and `Alfa`. All strict Slips remain Again.
`mapping_words` owns the same policy for supplied key identity and explanatory
feedback. No alias, fuzzy success or client-provided grade is introduced.

Study projects each immutable key-TAB-value Unit to its expected value before
grading and translates expected byte spans back to the complete stored Unit.
Typed byte spans still refer to the exact raw answer. Historical text Attempts
continue using the original `grade`/`GRADER_VERSION` unchanged.
