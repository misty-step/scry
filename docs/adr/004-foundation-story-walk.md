# ADR 004: Adopt the Misty Step foundation contract and required story-walk gate

Status: adopted for MIS-150; contract source: [Misty Step foundation catalog](https://github.com/misty-step/harness/blob/master/agent-config/skills/foundation/foundation-standard-v1.json). The exact revision and catalog digest are pinned in [`foundation.json`](../../foundation.json) after the harness integration lands.

Scry keeps its product intent in [USER_STORIES](../../USER_STORIES.md), acceptance in [SPEC](../../SPEC.md), implementation map in [`features/`](../../features/README.md), and verification procedures in [Scry QA](../../.agents/skills/scry-qa/SKILL.md). The required CI foundation and story-walk jobs use a pinned harness checker and validate a source-bound, artifact-hashed receipt; an unwalked or failed affected story blocks the gate. An honest pending adoption disposition is not a compliance claim.

Choose the already-used **Playwright 1.63.0** browser module and distribution Chromium: [the existing Dagger gate](../../.dagger/src/index.ts) already installs that version and [the critic browser resolver](../../scripts/critics/lib/browser.mjs) already locates it. `.exe/setup.sh` installs the test-only module in a user-owned prefix and the browser with Ubuntu apt (only under noninteractive sudo); `qa/walk` invokes native pointer/keyboard interaction on the isolated VM. This adds **no application/runtime dependency** and no frontend build. CI provisions the same test-only browser; no secrets or provider requests are required. The fixture cannot prove real generation, protected production ingress, recovery or physical-phone acceptance; record these obligations pending until independent retained evidence exists.
